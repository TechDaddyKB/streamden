# StreamDen

*by Tech Daddy Digital · GPL-3.0-or-later (SDKs: MIT OR Apache-2.0)*

**One modern, cross-platform streaming automation hub.** It brings together what Streamer.bot, Speaker.bot and
SAMMI do, and adds a combined multichat, a WYSIWYG overlay and alert designer, VTuber tooling, JavaScript and
Python scripting, a plugin SDK, and a built-in MCP server for AI agents.

Runs on **Windows, Linux (Debian/Ubuntu, Fedora, Arch + AUR) and macOS**. Local-first: no mystery cloud.

> **Status:** planning and spikes (October 2026). No product code yet. Start with [PLAN.md](PLAN.md).
