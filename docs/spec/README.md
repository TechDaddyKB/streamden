# Subsystem Specs

Specs are written **after** the Round-1/Round-2 questions in [`../QUESTIONS.md`](../QUESTIONS.md) are answered.
One file per workstream (see [PLAN.md §4](../../PLAN.md)), using the "Spec writer" role prompt in
[`../agents/PROMPTING.md`](../agents/PROMPTING.md).

Each spec contains: scope and non-goals · user stories · data model · events/triggers · sub-actions · settings
(all with schemas) · API surface · UI flows · cross-platform notes · performance budgets · security · test plan ·
links to the FEATURE-PARITY rows it covers.
