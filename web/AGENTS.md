# web/ — agent notes

pnpm workspace packages (`pnpm-workspace.yaml`). Root `AGENTS.md` still applies.

- `web/ui` (`@streamden/ui`): React 19 + TypeScript + Vite app shown by `apps/desktop` and served to browsers.
  It is an API client like any other: no private endpoints, no custom Tauri commands (D-006). Generated
  protocol types come from `sdk/ts` once Spec 02 codegen lands; never hand-write wire types.
- `web/kit` (`@streamden/kit`): design tokens and components, later also exported as web components for plugins.
  Workspace packages import it from source (`exports` → `src/index.ts`), so no build order is needed; its
  `build` only proves the declarations emit.
- `web/overlay-runtime` (`@streamden/overlay-runtime`): light runtime for OBS browser sources. Keep it small and
  dependency-free; overlays are always served by our local server (S-2).
- **No WebGL** in the main UI or designer (WebKitGTK + NVIDIA on Wayland).
- Dependencies are pinned to exact versions. Add them with `pnpm add --filter <pkg> <name>@<version>`, respect the
  pnpm `minimumReleaseAge` supply-chain policy (never weaken it), and note the license in your handoff.
  `pnpm-lock.yaml` is single-writer and regenerated by pnpm, never hand-edited.

Checks: `pnpm install --frozen-lockfile --ignore-scripts`, `pnpm -r build`, `pnpm -r typecheck`.
